# 追加の旅「佐賀のまち」の資料と再現範囲

2026-10-16制作。実在する外観をコードで立体化し、移動の距離を縮めた160×156の箱庭にまとめた。写真の貼り付け、Google Mapsの画面や透かしのゲーム内利用はしていない。遊びは従来と同じく、人間以外の住人と巡る穏やかな謎解き。

## 川久保の建物

ユーザー指定：佐賀県佐賀市久保泉町川久保869。追加の地図画像に表示された座標は **33.324335, 130.326075**。

- Google Mapsの地図・航空写真を開き、指定地点、周囲の道路、建物の輪郭、佐賀駅・モラージュとの方位関係を確認した。
  - https://www.google.com/maps/@33.324335,130.326075,19z?hl=ja
  - https://www.google.com/maps?q=33.324335,130.326075&z=20&t=k&hl=ja
- ライブのStreet Viewは、この環境の指定地点では「ここにはストリートビュー画像がありません」となった。外観の主な目視根拠は、ユーザーが提供した**2024年5月のGoogle Street View画像4枚**と、座標・敷地全景の追加画像1枚。
- 写真1：玄関・右庭・石灯籠・隣家と瓦塀。写真2：母屋正面、段違いの切妻、松、網代状の腰壁、3段階段。写真3：波板作業場の中庭側。写真4：作業場西側切妻、錆筋、電柱・生活道路。写真5：全景と位置関係。

`src/stages/saga/kawakubo.js` は、この写真に見える母屋・作業場・塀・庭・隣家を、1 unit≒1mの概算比率で再構成する。瓦は湾曲した反復形状、波板と錆・腰壁は手続きテクスチャ、松は段ごとに分かれる葉と枝で構成した。写真を使った輪郭・比率・色の比較を行い、実描画を見て瓦の二重着色、松の形と位置、錆の強さ、背景樹冠を調整した。

測量や建築図面による実測モデルではない。写真に写らない背面・奥行き・屋根裏などは中立に補完し、室内や所有者・居住者の設定を作らない。車のナンバー、氏名、電話番号、住所ラベルをゲームには入れない。観察の机や住人は敷地の外側に置く。

## 広域配置とゲーム上の創作

北を-z、東を+xとし、川久保を駅の北東、モールを駅の南東に置く。地域間の距離は大きく圧縮し、施設ごとの模型をそれぞれ縮尺配置する。駅.45、モール.16、川久保.95。**全地点を共通縮尺で測量した市街地図ではない。**道路は各地域をつなぐ箱庭用の道で、現実のルートや所要時間を表さない。

「ほしまわり臨時便」の時刻、寄り道市の価格、クリーク広場、気球の盤面・風予報は、謎解き用の架空設定。ゲーム内でも実ダイヤ・実売価格と区別できる短い説明を付ける。公的施設や住宅の内部へ進む遊びは設けない。

旅ノートには各施設の近景、モール全体、川久保の3方向、箱庭全体へ移る案内を用意した。従来のOrbitControlsの操作はそのまま、対象地域でのみ低い写真の目線へ視点を下げられる。

昼光で外壁や地図の色を保つため、このステージのブルームは控えめにする。雲海の白面からの光のにじみを抑え、縦画面の全景でも田畑・建物・道を区別できるよう調整した。AO・被写界深度と建物の造形は通常画質のまま維持する。
