# 嵜本ベーカリー・山カフェレストランKUREHAの外観資料

参照日：2026-10-18。取得した写真を目視し、外観の形・色・配置を模型へ反映した。写真そのものはゲームの素材へ複製せず、すべてthree.jsの形状とコードで描く壁材・文字で表現する。制作を中断している生成画像も使っていない。

## 嵜本ベーカリー

- [嵜本公式・佐賀店](https://shokupan-sakimoto.com/shop/saga/)。店舗一覧と個別ページを取得し、佐賀市大財4-2-9の店舗であることを照合。
- [公式掲載の店舗外観写真](https://shokupan-sakimoto.com/wp-content/uploads/2022/06/saga-shop_01.jpg)を取得・目視。

写真にある、背の高い切妻屋根、正面の斜め木板、右上の白い壁と水平ルーバー、黒い縦桟の窓、右側の低い入口庇、木の柱・軒裏の垂木、店先の細い植栽を再現する。大きな黒い箱や縞の布庇にはしない。正面の壁面に「嵜」「SAKI / moto / bakery」を配置する。

`src/stages/saga/sakimoto.js` の `buildSakimoto(parent, {x, z, scale=1})` が模型を返す。戻り値は `root`・`sign`・`recommendation`・`view`・`footprint`。既存の街角の約7.2×5区画へ収めるため、建物の奥行きと入口の横幅を圧縮し、入口面は箱庭の正面からも見えるように組み替えている。写真に写らない内部の正確な再現ではない。窓の奥のパン棚と「いちごミルク食パン」の商品札・断面は、ユーザー指定のおすすめ品を示すゲーム上の演出。

## 山カフェレストランKUREHA

- [公式サイト](https://www.bios-saga.co.jp/)のトップページを取得。
- [公式の玄関写真（pc_slide_11）](https://www.bios-saga.co.jp/60012259/wp-content/uploads/2020/06/pc_slide_11.jpg)を取得・目視。クリーム色の壁、濃茶の木枠と太い丸柱、わずかに反った破風、緑青色の屋根、木々に囲まれた石段を参照。
- [公式のダイニング写真（pc_slide_12）](https://www.bios-saga.co.jp/60012259/wp-content/uploads/2020/06/pc_slide_12.jpg)を取得・目視。木枠の大窓、梁、濃い背もたれの椅子、明るい壁を参照。
- [mikuLogの訪問記事](https://fuku-life.com/kurehalunch/)を取得し、[街道側の門の写真](https://fuku-life.com/wp-content/uploads/2022/11/Screenshot_20221107-222038-1.jpg)を目視。広い薄い緑色の屋根、白い横目地の壁、外側の木柱、門の奥へ上る石段を参照。

`src/stages/saga/bistro.js` の `createFoamBistro(parent)` は既存の関数名と操作対象のAPIを保ち、模型をKUREHAへ置き換える。以前の架空店の縞の布庇・レンガ腰壁は撤去。18×14の区画へ収めるため、道路側の門と高台の館の距離・高低差を圧縮し、門を左、窓越しのダイニングを右に見せる。実際の敷地全体の測量再現ではない。テラスの任意体験とサラダの位置・`saFoamTasted`による記録は維持する。テラスの家具・配膳はゲーム上の演出であり、現在の席配置やメニューの営業案内ではない。

## 使用しなかったページ

最初に推測した `www.kureha-saga.com` はプロキシで403となり参照していない。検索結果から公式の `www.bios-saga.co.jp` を確認し、その取得できた写真を使用した。Google検索は確認画面のみで、Googleマップ・ストリートビューを新たに取得したという扱いにはしていない。
