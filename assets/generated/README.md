# 生成画像素材（82枚・組み込み済み）

2026-10-18、予定していた82枚すべての生成と保存を完了した。各PNGは一つの持ち物、または一種類の表面素材だけを収めている。

生成原本を保管したまま、軽量なWebP版をゲームに組み込んだ。持ち物・入手通知・使用カーソルと、箱庭の表面素材に使う。模型の形・謎の答え・持ち物ID・セーブ形式は維持している。

## 内容

- `items/`：持ち物61種類を63枚。薬3種類は別々の画像。背景透過のPNG。
- `materials/`：草地・土・石・木・漆喰・瓦・布・和紙・金属・ピクセル石壁・床など19枚。背景不透明のPNG。
- 全画像1254×1254ピクセル。再開前に保存した5枚を含む。
- [画像確認一覧](catalog.html)：各画像を個別に原寸表示できる。持ち物には明暗の背景で64px表示、表面素材には繰り返し表示を用意。
- [制作条件](generation-plan.json)：82枚のID・被写体・共通の画風。
- [保存一覧](manifest.json)：採用版のパス・生成原本名・寸法・透過設定・SHA-256・状態。

## 確認済み

- 計画の82 IDと保存済み82ファイルが一致し、画像内容の重複がない。
- 全PNGを読み込み、寸法と背景透過・不透明を確認した。
- 月の歯車は三日月形の透過穴と28個の歯を確認。水入りの指ぬきは、広い口が上、丸い閉じた底が下になる形へ修正した。
- 生成は画像生成ツールで一素材ずつ行った。複数素材を一枚のシートにまとめていない。修正前の生成原本を削除していない。

## ゲーム内の使い方

- 看板・暖簾の文字はコードで最後に重ねる。手紙・地図・札・手ぬぐいの画像は持ち物アイコンとして使い、読むときは既存の正確な謎パネル・メモを表示する。
- 旅のノートの図はアイコン用であり、実際の地理を表す案内図には使わない。
- 配信用は `../runtime/items/`（320px・透過）と `../runtime/materials/`（512px）。82枚で合計約3.2MiB。勇者・魔王のピクセル壁は最近傍縮小・可逆圧縮・最近傍描画を使う。
- `src/lib/item-art.js` が画像未取得・通信失敗時は従来のSVGを表示する。薬のセットは別々の3枚をUI上で並べ、ゲーム上の持ち物は一つのまま。
- `src/lib/surface-art.js` が必要なステージの素材を先読みする。待機は最大2.5秒で、後から届いた素材も文字を再描画して反映する。未取得の間は元の基調色を使う。材質の色・木目の向き・縮尺を調整し、繰り返しの境界はミラーでつなぐ。

## 配信用画像を作り直す

Pillowを用意して、リポジトリ直下で `python3 tools/pack-generated-assets.py` を実行する。生成原本は変更せず、配信WebP・`assets/runtime/manifest.json`・`src/data/generated-art.js` を更新する。ゲーム起動時の生成処理や追加ビルドは不要。

`npm run check` と `node tools/generated-art-regressions.mjs` で構文・画像の読み込み・代替表示を確認する。
