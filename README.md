# ほしまわり列車 〜異世界箱庭謎解き〜

異世界を旅する列車「ほしまわり号」に乗って、ミニチュアの箱庭をめぐる謎解きゲームです。
three.js で作った浮島のジオラマを回したり拡大したりしながら、住人（人間ではない生き物たち）と話し、
アイテムを集めて謎を解き、列車を次の世界へ出発させます。

## 遊び方

ビルド不要です。静的ファイルを配信できるサーバーで `index.html` を開いてください
（ES Modules を使うので `file://` 直開きでは動きません）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages などにそのまま置いても動きます。three.js は `vendor/` に同梱しています。

スマホのホーム画面にも追加できます。AndroidのChromeでは右上の「︙」→「ホーム画面に追加」、iPhoneのSafariでは共有→「ホーム画面に追加」を選びます。Chromeが「すでにインストールされています」と表示する場合も、「ショートカットを作成」からこのゲームへのアイコンを追加できます。

`manifest.webmanifest` で、このゲーム専用のアプリID `/iyashinazo/`、配信フォルダ内だけの範囲、クエリなしの起動URL、専用アイコンを指定しています。同じGitHub Pagesドメインの別ゲームと共通のアプリIDを使わないための設定です。別のリポジトリへコピーして公開する場合は、そのゲーム独自のIDに変更してください。ホーム画面への追加後も、読み込みには通信が必要です。


| 操作 | 内容 |
| --- | --- |
| ドラッグ | 箱庭を回す |
| 右ドラッグ・Shift+ドラッグ / 2本指 | 視点を動かす |
| ホイール / ピンチ | 指している場所に寄る・引く |
| 何もない所をダブルクリック / ダブルタップ | そこを画面の中心にする |
| 画面右の ＋ － ⟲ ⟳ ⌂ | 寄る・引く・45°回る・全体を見る |
| WASD・矢印 / Q・E / R・F | 視点を動かす / 回す / 寄り引き |
| クリック / タップ | 調べる・話しかける |
| 持ち物を選んでからクリック | アイテムを使う |
| 💡 / H キー | ヒント（押すたびに詳しく） |
| ✨ | 調べられる場所を光らせて、名前を出す |
| タイトルの「路線図」 | クリアした駅と次の駅を選んで遊べる（まだ見ぬ駅は「？？？」） |
| 路線図の「追加の旅」 | 本編クリア後、好きな追加ステージへ。各旅の続きから／最初からを選べる |
| 📖 / M キー | 旅のメモ（見つけた手がかりが自動で書きとめられる・会話のきろく） |

進行状況はブラウザに自動セーブされます。セーブは端末・ブラウザごとなので、ほかの端末で続きを遊ぶときは、クリア画面やメニューに出る「あいことば」をタイトルの「あいことば」に入れると、その駅から始められます。重い場合は `?low` を付けると軽量モードになります。

## ステージ

1. **はざま駅** — 世界のあいだの小さな駅（実装済み・約15分）
2. **天空の街** — 雲の上の風車の街（実装済み・約15分）
3. **江戸の宿場町** — 夜明け前の宿場と浅草寺（実装済み・約15分）
4. **潮の港町** — 潮の満ち引きの港（実装済み・約15〜20分）
5. **勇者の城下町** — お城と市場のにぎわい（実装済み・HD-2D風のドット絵・約20分）
6. **魔王城** — 紫の炎の城（実装済み・HD-2D風のドット絵・約20分）
7. **寂れた温泉街** — 湯けむりと提灯の路地（実装済み・約15分）
8. **巨大キノコの森** — 雨上がりの小さな世界（実装済み・約15〜20分）
9. **からくりおもちゃの街** — ゼンマイじかけの街（実装済み・1.5倍の大きさ・約20分）
10. **現代日本** — いつか見た、あの町（実装済み・終点・2倍の大きさ・約25〜30分）

順番は `src/data/route.js` で決めています。まだ前の駅がないステージは `?stage=onsen` のように指定すると直接遊べます（動作確認用）。

本編10ステージをクリアすると、路線図の中に**追加の旅**が表示され、好きな追加ステージを選べます。クリア後のメニュー・クリア画面からも選べます。既存の本編クリア済みセーブでも解放され、本編の進行と、追加ステージごとの持ち物・メモ・経過時間・謎の途中状態は別々に保存されます。

- **星あかりの博物館** — 夜間開館の博物館で、迷い星を夜空へ帰す（60×44、現代日本と同規模・約25〜30分を想定）。
- **佐賀のまち** — 佐賀駅からモラージュ佐賀、川久保の街角へ。実在の外観と、五つの寄り道を巡る広い箱庭（160×156）。

追加の旅は現在2ステージ。どちらを先に選んでも、本編やもう一方の旅の進行は残ります。

### STAGE 1：はざま駅

夕暮れの空に浮かぶ乗りかえ駅。異界特急「ほしまわり号」を天空の街へ出発させるため、
4つの準備（切符・火・水・信号）を整えます。

住人：ネコの駅長 / フクロウの切符係 / カエルの機関士 / ウサギの旅人 / カラス / ネズミのきょうだい

<details>
<summary>攻略（ネタバレ）</summary>

- **切符**：鉢植えのビー玉 → カラスと交換でゼンマイ鍵 → 待合室の時計を巻き、時刻表のメモ（かえるぬま行き5時の3時間後）から **8時** に合わせて鐘を鳴らす → フクロウが起きる。井戸からブローチ → ウサギに返して星の硬貨 → フクロウに渡して切符。
- **火**：倉庫の錠前は駅舎正面の丸窓の色 **黄・青・赤** → 火ばさみ → ストーブのほのお石 → カエルの機関士へ。
- **水**：切り株の家のネズミとかくれんぼ（荷物の山・大きな木のうろ・丸ポスト）→ バルブハンドル → 給水塔へ。
- **信号**：火と水がそろったら駅長から信号所の鍵 → レバーを出発の早い順 **きりのもり → かえるぬま → てんくうのまち → つきのうら**。
- 最後に駅長へ話しかけて出発。

</details>

### STAGE 2：天空の街

雲の上に浮かぶ、白い家と風車の街。線路をふさぐ雨雲を吹きとばすため、止まった大風車を直します。
はざま駅をクリアすると「次の世界へ」から行けます。

住人：ヒツジの町長 / アルパカの仕立て屋 / ツバメの郵便屋 / カメの時計台守 / モモンガの気球乗り / 空クジラ / カエルの機関士

<details>
<summary>攻略（ネタバレ）</summary>

- **帆**：アルパカに頼むと雲のわたが3つ必要。噴水 / 気球（カエルの油さしで巻き上げ機を直して気球を下ろし、モモンガから）/ ツバメの巣（バラのアーチで見つけた手紙を見せる）→ 雲の帆 → 大風車へ。
- **歯車**：手紙をカメの時計台守に届けて読むと「そらのうた」がわかる。手紙の記号を時計台の鐘の札とリボンで色におきかえ（☾＝青・★＝黄・☁＝白・☀＝赤）、宝箱の鈴を **青 黄 白 赤 白 黄** の順に鳴らす → 歯車 → 大風車へ。
- **風の道**：風穴の前で眠る空クジラに町長のこんぺいとうをあげてどいてもらい、風の配管盤のパイプを回してつなぐ。
- 3つそろったら町長へ。大風車が回って雨雲が晴れ、出発。

</details>

### STAGE 3：江戸の宿場町

夜明け前の宿場町。浅草寺の雷門と五重塔、瓦屋根の町家、太鼓橋のかかる川。
明け六つの鐘が鳴らないので夜が明けず、線路をふさぐ町木戸も開きません。
（STAGE 10「現代日本」は、この場所の二百年後という設定です）

住人：浅草寺の狛犬 / ツルの鐘つき番 / ネコの瓦版屋 / イヌの岡っ引き / カッパの渡し守 / リスの団子屋

<details>
<summary>攻略（ネタバレ）</summary>

- **瓦版**：瓦版屋のネコの版木合わせ（こまを2つ選んで入れかえ、『江戸名所』の絵にもどす）→ 瓦版。鐘の撞きかたと、親分の十手のことが書いてある。
- **鐘**：ツルの鐘つき番は引き綱が切れて困っている → 井戸のキュウリをカッパにあげて舫い綱 → 時の鐘に使う → 「撞く」3回 →「間をおく」→「撞く」6回。夜が明ける。
- **手形**：岡っ引きのイヌは十手をなくしている → 朝になってから太鼓橋を調べると川底に十手 → 開店した団子屋のリスから団子 → カッパにあげると潜って十手を取ってくる → イヌに返すと通行手形。
- 3つそろったら狛犬へ。町木戸が開いて出発。

</details>

### STAGE 4：潮の港町

朝霧につつまれた、白い壁と青い屋根の港町「しおのみなと」。町の潮時計が止まって潮は満潮のまま。
線路は海の中の「潮の道」にもぐり、灯台にも灯がともりません。
**潮時計で満潮・中潮・干潮を切りかえると、海の高さで行ける場所が変わります。**

住人：アザラシの灯台守 / タコの郵便屋 / カニの漁師 / ペリカンの魚屋 / カモメ / カエルの機関士

<details>
<summary>攻略（ネタバレ）</summary>

- **潮時計**：宛名のにじんだ郵便の仕分け（二十八の歯＝月のひとめぐり→潮見やぐら、冷たいの三箱→魚市場、すすの出にくい品→灯台、つくろい糸→網小屋）→ 月の歯車と灯台あての小包 → 潮時計に歯車を入れると潮を変えられる。
- **干潮**にすると砂州・洞窟・潮の道が出る。アザラシは砂州を渡って灯台へ帰り、芯（小包）と灯台の油がいると言う。
- **魚**：ペリカンは魚がないと油を出さない → カニの漁師の網は洞窟（干潮）→ 網をわたすと「石橋の下をくぐる。満潮はマストがつかえ、干潮は船底がつかえる」→ **中潮**にすると漁に出て、アジをくれる → ペリカンへ → 灯台の油。
- **灯台**：干潮で灯台へ。小包と油をアザラシにわたし、レンズの輪をそろえる（「外と中」2回・「中と内」1回）→ 霧がはれる。
- 3つそろったら**干潮**にしてカエルの機関士へ。潮の道をわたって出発。

</details>

### STAGE 5：勇者の城下町

丘の上にお城のそびえる、RPG のような城下町（ほかの街の約1.5倍の広さ）。
この世界だけ、住人も建物の表面も**ドット絵**（HD-2D風）になり、会話の窓もRPG風になります。
ハリネズミの勇者の旅立ちの準備がそろうまで、王様は跳ね橋を下ろしてくれません。
**宿屋に泊まると昼と夜が入れかわり**、会える住人や調べられる場所が変わります。

住人：ハリネズミの勇者 / スライムの道具屋 / ゴブリンの鍛冶屋 / 子ドラゴン / ライオンの王様 / アルマジロの門番 / フクロウの占い師（夜） / カエルの機関士

<details>
<summary>攻略（ネタバレ）</summary>

- **子ドラゴン**：竜舎のむらさきの封筒（魔界の手紙）→ 夜、ギルドの前の占い師に見せる → 昼、教会のステンドグラスで対応表 → 手紙を2回押して解読「**あいたい**」（「た」は対応表で欠けているので意味から）→ 元気になって、鍛冶屋の炉に火をつけてくれる。
- **剣**：ゴブリンの手引き「白で一度、黄で二度、橙で一度。そして水」→ ふいご4回・打つ・打つ・ふいご・打つ・打つ・水 → 勇者の剣を勇者へ。
- **薬**：スライムに月光草（夜・教会の庭）とゴールド袋3つ（昼：宿屋の前のつぼ・鍛冶屋の横のたる・竜舎の宝箱／夜：教会の裏の木箱・市場のつぼ）→ 色まぜ（回復薬＝黄2青1、毒消し＝赤1青2、元気の素＝赤2黄1）→ 薬のセットを勇者へ。
- 3つそろったら昼に王様へ。跳ね橋が下りて、勇者と子ドラゴンもいっしょに出発。

</details>

### STAGE 6：魔王城

夕やけの空にそびえる、紫の炎と溶岩の谷の城（HD-2D風）。勇者と子ドラゴンといっしょに着くと、
魔王（子ドラゴンの兄）はずっと玉座でうしろを向いたまま。戦うのではなく、さみしい魔王のために夕食会をひらきます。
**紫の炎のランタン**を灯すと見える物（ゴースト・隠し文字）と、消すと見える物（暗がりのキノコ・燭台のゴースト）があります。

住人：ドラゴンの魔王 / コウモリの執事 / 骸骨の門番 / 魔女ネコの料理番 / ミミック / ちびゴースト / ハリネズミの勇者 / 子ドラゴン / カエルの機関士

<details>
<summary>攻略（ネタバレ）</summary>

- **城門**：執事からランタン → 灯すと門の上に魔界文字 → 駅前の石碑の対応表で読む「**おとうと**」→ 門番に合言葉。
- **ゴースト**：ランタンを灯して肖像画の回廊を見ると、かくれ場所がわかる → 噴水の上・台所の大鍋・図書室の本棚（灯して）、消えた燭台（消して）。本棚のゴーストが星くず塩をくれる。
- **シチュー**：魔女ネコ → 黒板（灯して読む）「トマト→キノコ→塩、3回まぜる」→ 溶岩トマト（谷のふち）・かげキノコ（地下牢、ランタンを消す）・星くず塩。
- **絵本**：ミミックのなぞなぞ（消えた燭台はひとつ・肖像画は5まい・合言葉は「おとうと」）。
- 3つそろったら玉座の魔王へ。夕食会のあと跳ね橋が下りて出発（勇者と子ドラゴンは城に残る）。

</details>

### STAGE 7：寂れた温泉街

雪のちらつく山あいの湯の町「ゆげのさと」。源泉が止まって湯けむりも灯りも消え、線路の先のトンネルは氷でふさがれています。
町に灯りと湯をとりもどし、トンネルの氷をとかします。

住人：カピバラの湯守 / キツネの提灯屋 / タヌキの番頭 / 子ザル / 湯治のサルたち / カエルの機関士

<details>
<summary>攻略（ネタバレ）</summary>

- **火**：キツネから手さげ提灯 → 旅館「たぬき屋」の囲炉裏そばの火かき棒 → 釜場に使って残り火をかき出す → 提灯を釜場に使って火をともす。
- **灯り**：灯った提灯をキツネに見せる → 提灯やぐら（ひとつ押すと上下左右も入れかわる）を **四すみ＋まんなか** の5つで全部灯す。
- **門**：灯った提灯を旅館の囲炉裏に使う → 起きたタヌキから甘酒 → 露天風呂の子ザルにあげて源泉の門の鍵 → 山の上の門へ。
- **湯**：共同浴場の三合升を源泉に置き、五合升と三合升で **ちょうど四合**（五合を汲む→移す→三合を捨てる→移す→五合を汲む→移す）を樋へ流す。
- 3つそろったらカピバラへ。湯がトンネルの氷をとかして出発。

</details>

### STAGE 8：巨大キノコの森

雨上がりの森の地面を、虫の目線で旅するステージ。キノコは家ほど、5円玉は車輪ほどの大きさです。
ゆうべの大雨で線路に落ちた枯れ枝を、森いちばんの力持ちのカブトムシにどけてもらいます。

**赤いキノコ**の胞子でカエルの機関士が大きく、**青いキノコ**の胞子で小さくなります。
大きいと重い物や高い所に、小さいとせまい所や小さな字に手がとどきます。

住人：キノコの長老 / カタツムリの郵便屋 / アリの隊長と行列 / テントウムシの子どもたち / ホタルの灯り番 / クモの機織り / カブトムシ / カエルの機関士

<details>
<summary>攻略（ネタバレ）</summary>

- **車輪**：カタツムリの郵便車の車輪は「まんまるで、まんなかに穴がひとつ」→ 大きくなってぬかるみの **5円玉** を引っぱり出す（ボタンは穴が4つでだめ）→ 百年前の手紙を長老へ → 宝の地図。
- **地図**：「切り株から北へカタツムリ2ひき、東へテントウムシ4ひき」。小さくなってアリの巣の立て札を読む（カタツムリ1＝アリ3、テントウムシ1＝アリ2）→ 北へアリ6、東へアリ8。大きくなって広場を掘ると、ゆびぬき。
- **蜜**：大きくなって、しずくの葉からゆびぬきにしずくを受ける → あまつゆ草に水をあげると咲いて、蜜。
- **影絵**：クモが巣につのの型を編む → 小さくなって釣鐘草のホタルを起こす → ふたまたの小枝・上下そのまま・ホタルの位置で大きさを合わせる（影＝物の大きさ×（ホタル〜巣）÷（ホタル〜物））→ カブトムシが飛び起き、クモから綱。
- 蜜をカブトムシにあげて、綱がそろったらカブトムシへ。枝を島の外へ放りなげて、虹の下でお茶会。

</details>

### STAGE 9：からくりおもちゃの街

積み木の家、ブリキの塔、道路のプレイマットの、夕やけ色のおもちゃの街（城下町と同じ1.5倍の大きさ）。
時計塔の大ゼンマイがほどけて、街じゅうのおもちゃと、川のはね橋が止まっています。

**ゼンマイ鍵**で、止まったおもちゃを巻くと動き出して、力を貸してくれます。

住人：クマのぬいぐるみの町長 / ブリキのロボット犬 / ゼンマイネズミ / 積み木の恐竜 / オルゴールのウサギ / ブリキの機関車 / ゴムのアヒル / カエルの機関士

<details>
<summary>攻略（ネタバレ）</summary>

- **歯車**：ロボット犬を巻く（針は右回り、大ゼンマイ2回で1回）→ 砂場を掘って歯車箱 → 時計塔の歯車の窓。あいだの歯車は向きを変えるだけ。**あいだを奇数こ（1か3）、針の歯車は歯24**。
- **歌**：ウサギを巻く → 恐竜を巻くとおなかの下から楽譜⚀、ブリキの機関車を巻くと貨車に楽譜⚁ → 木琴の橋で色と音（赤ド・橙レ・黄ミ・緑ソ・青ラ）→ オルゴールに **ミソラソ／ミレミド**。

### 追加の旅：星あかりの博物館

月明かりと真鍮の灯りに包まれた、夜間開館の博物館。化石の骨格、収蔵書庫、鉱石と月の花の温室、光の実験室、中央の天文ドームを、好きな順番で巡れます。
4つの展示の印を集め、迷い星の帰り道を天球儀に映しましょう。達成すると展示そのものが変化し、最後は星を見送ります。庭の望遠鏡では3つの小さな星座も探せます。

住人：フクロウの館長／キツネの修復士／ラッコの司書／カメの庭師／モモンガの光技師／カエルの機関士。
掲示の内容と集めた印は、旅のメモと「夜の観覧手帳」で読み返せます。タイミング操作や外部知識は不要です。

<details>
<summary>攻略（ネタバレ）</summary>

- **地層**：下（古い）から、貝 → 魚 → 葉 → 羽 → 足跡。2枚ずつ選んで交換する。
- **書庫**：台車は階段を通れない。9通路以内に3棚を回り搬出口へ。例：受付 → 西通路 → 貝の棚 → 丸窓 → 羽の棚 → 東通路 → 葉の棚 → 搬出口。別解も受け付ける。
- **月の花**：5Lを満たす → 3Lへ注ぐ → 3Lを空に → 残り2Lを3Lへ → 5Lを満たす → 3Lへあと1L注ぐ。5L側に4L残る。
- **光の回廊**：光が通る順に鏡を「／、／、＼、／、＼」。5枚すべてを経由して出口へ。
- **天球儀**：北=0、時計回りに8方位。貝=西（6）、羽=北東（1）、葉=北（0）、星=南東（3）。星の道がつながったら館長へ。

</details>

### 追加の旅：佐賀のまち

五月の明るい空の下、佐賀駅、モラージュ佐賀、ユーザー指定の川久保の建物を巡るまちあるき。
佐賀駅の南口と大屋根、モラージュの北館・南館・シネマ・駐車場、川久保の母屋・波板の作業場・松・瓦塀を、写真や地図を参照してコードで立体化しています。
川久保は提供写真の外観と配置を優先した造形で、正面・左の路地・庭側に加え、玄関と腰壁・瓦塀・作業場の近景から見られます。参照資料と再現範囲は[佐賀の資料](docs/saga-references.md)、[佐賀駅](docs/saga-station-references.md)、[モラージュ佐賀](docs/saga-mallage-references.md)にまとめています。

島は160×156。地域間の距離を圧縮し、3地点の模型をそれぞれの縮尺（佐賀駅0.45、モラージュ0.16、川久保0.95）で配置した箱庭です。
施設内の比率を保ちつつ、広い平野と街の景色を一緒に眺められる構成で、現実の道路地図や共通縮尺の市街地模型ではありません。
住人との遊びは、臨時便の旅程、おみやげの買物、クリークの水門、バルーンの風読み、街角の観察の五つ。好きな順で巡り、スタンプを集めて旅の便りを仕上げます。

北西には**アマンディ佐賀**と、架空の**ビストロ 翠の泡**があります。アマンディは[公式写真・館内図など](docs/saga-amandi-references.md)を基に本館・車寄せ・プール棟・浴場を造形。ビストロでは「苦い泡のドレッシング」のサラダを味わえます。商店、共同住宅、公園、自転車置場、クリークの小橋など14の小景も追加し、パン屋・花屋・公園・小橋に立ち寄ると旅のメモに記録されます。
温浴施設での休憩と食事は自由な寄り道で、五つの謎のスタンプとは別に保存されます。既存の佐賀の途中セーブからも、進行を保ったまま訪ねられます。

**ラウンドワンスタジアム佐賀店・井手ちゃんぽん大和店・忠兼総本社**も、公開資料や外観写真を参照した模型として街区に追加。ラウンドワンでは時間制限のないミニボウリング、大和店ではちゃんぽんの食事、忠兼総本社では黄色いひさしと窓辺の観察を楽しめます。必須の五つの謎とは別の任意の記録で、最高記録や旅のメモは保存されます。[3施設と川久保の精密化の資料](docs/saga-city-references.md)も参照してください。

住人：カササギの旅案内／ネコの駅長／ウサギのおみやげ係／ツルの水番／モモンガの飛行士／カエルの機関士／カピバラの湯案内／キツネの料理人。
持ち物の「佐賀の旅ノート」から各施設の近景・モール全体・川久保・アマンディ・翠の泡・ラウンドワン・井手ちゃんぽん・忠兼総本社・北西の散歩道・クリーク・バルーン広場・箱庭全体へ視点を移せます。
手がかりは旅のメモとノートで読み返せ、各謎の入力途中も自動保存されます。臨時便の時刻や催事の価格はゲーム用の設定です。

## 開発時の確認

```sh
npm install
npm run check                         # 構文・アイテムID重複
node tools/save-regressions.mjs        # ブラウザ不要：旧保存・本編と追加2旅の往復・やり直し
node tools/saga-logic-regressions.mjs  # ブラウザ不要：佐賀の五つの謎の条件と答え
npm run serve                         # ブラウザ確認用。別のターミナルで起動しておく
node tools/extra-regressions.mjs       # 追加旅の選択・保存・復帰（箱庭は軽い仮実装）
node tools/saga-regressions.mjs        # 佐賀のパネル個別操作・途中再開・縦横画面
node tools/saga-stage-regressions.mjs  # 佐賀の実箱庭・視界・行き先・保存・終幕の個別確認
node tools/saga-northwest-regressions.mjs # 北西施設の任意体験・旧保存・街角・縦横UI・既存の視界
node tools/saga-city-regressions.mjs # 新3施設・遮蔽・任意体験と最高記録・家の近景・保存
```

ブラウザを使う確認は一つずつ実行します。`CHROMIUM` で実行ファイルを指定できます。
`?stage=saga&low` では、本編のクリアを待たず佐賀の箱庭だけを確認できます。
通しプレイはユーザーから別途指示があるときに行い、通常は変更箇所を個別操作・撮影して、画像も目で確認します。
