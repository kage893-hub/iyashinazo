# ほしまわり列車 〜異世界箱庭謎解き〜

異世界を旅する列車「ほしまわり号」に乗って、ミニチュアの箱庭をめぐる謎解きゲームです。
three.js で作った浮島のジオラマを回したり拡大したりしながら、住人（人間ではない生き物たち）と話し、
アイテムを集めて謎を解き、列車を次の世界へ出発させます。

## 遊び方

ビルド不要です。静的ファイルを配信できるサーバーで `index.html` を開いてください
（ES Modules を使うので `file://` 直開きでは動きません）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages などにそのまま置いても動きます。three.js は `vendor/` に同梱しています。

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 箱庭を回す |
| 右ドラッグ / 2本指 | 視点を動かす |
| ホイール / ピンチ | 拡大・縮小 |
| クリック / タップ | 調べる・話しかける |
| 持ち物を選んでからクリック | アイテムを使う |
| 💡 / H キー | ヒント（押すたびに詳しく） |
| ✨ | 調べられる場所を光らせる |
| 🏠 | 駅舎の屋根を外す（近づくと自動でも外れる） |

進行状況はブラウザに自動セーブされます。重い場合は `?low` を付けると軽量モードになります。

## ステージ（路線図）

1. **はざま駅** — 世界のあいだの小さな駅（実装済み・約15分）
2. 天空の街（準備中）
3. 寂れた温泉街（準備中）
4. 勇者の城下町（準備中）
5. 現代日本（準備中）

### STAGE 1：はざま駅

夕暮れの空に浮かぶ乗りかえ駅。異界特急「ほしまわり号」を天空の街へ出発させるため、
4つの準備（切符・火・水・信号）を整えます。

住人：ネコの駅長 / フクロウの切符係 / カエルの機関士 / ウサギの旅人 / カラス / ネズミのきょうだい

<details>
<summary>攻略（ネタバレ）</summary>

- **切符**：鉢植えのビー玉 → カラスと交換でゼンマイ鍵 → 待合室の時計を巻き、時刻表のメモ（かえるぬま行き5時の3時間後）から **8時** に合わせて鐘を鳴らす → フクロウが起きる。井戸からブローチ → ウサギに返して星の硬貨 → フクロウに渡して切符。
- **火**：倉庫の錠前は駅舎正面の丸窓の色 **黄・青・赤** → 火ばさみ → ストーブのほのお石 → カエルの機関士へ。
- **水**：切り株の家のネズミとかくれんぼ（荷物の山・大きな木のうろ・丸ポスト）→ バルブハンドル → 給水塔へ。
- **信号**：火と水がそろったら駅長から信号所の鍵 → レバーを出発の早い順 **きりのもり → かえるぬま → てんくうのまち → つきのうら**。
- 最後に駅長へ話しかけて出発。

</details>

## 構成

```
index.html              エントリ（import map で vendor の three.js を参照）
css/style.css           UI のスタイル
src/main.js             タイトル・HUD・起動処理
src/core/               ゲームエンジン（描画/入力/状態/会話UI/音/ポストエフェクト）
src/lib/                共通の造形（生き物・空や浮島・ヘルパー・メッシュ結合）
src/data/items.js       アイテム定義（SVG アイコン）
src/stages/registry.js  ステージ一覧（路線図）
src/stages/station/     STAGE 1 はざま駅（箱庭・列車・謎解き・パネル）
vendor/three/           three.js r169（MIT）
```

新しいステージは `src/stages/<id>/` にステージクラス（`build` / `applyState` / `update` /
`quests` / `hint` / `useItem` / `opening` を持つ）を作り、`registry.js` に登録して追加します。
グラフィックはすべてコードで生成しており、音も Web Audio で合成しているので外部アセットはありません。
